El tema Stack de Hugo soporta la creación de galerías de imágenes interactivas usando Markdown. Está impulsado por [PhotoSwipe](https://photoswipe.com/) y su sintaxis se inspiró en [Typlog](https://typlog.com/).

Para usar esta función, la imagen debe estar en el mismo directorio que el archivo Markdown, ya que usa la función de page bundle de Hugo para leer las dimensiones de la imagen. **No se soportan imágenes externas.**

## Sintaxis

```markdown
![Imagen 1](1.jpg) ![Imagen 2](2.jpg)
```
